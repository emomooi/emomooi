**网文维权助手** —— 帮网文作者快速搜索盗版链接、一键投诉的浏览器扩展。

正式版已上线Microsoft Edge扩展商店

官方下载地址：https://microsoftedge.microsoft.com/addons/detail/chfgebleelcbdnahedlmfbndcdbofkfh

-  十余个搜索引擎批量抓取

-  多书 × 多引擎 × 多页自动搜索

> 不用装软件，浏览器装上就能用。
